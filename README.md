# 
Este é um projeto para prova **site sobre músicas desenvolvido inteiramente em HTML**, estruturado de forma simples e direta com **3 páginas interconectadas** por um menu de navegação global. 
##  estrutura
O site é composto por quatro arquivos principais:

*   **`home.html` (Início):** Página de boas-vindas que introduz o tema do portal musical.
*   **`sobre.html` (Sobre o Estilo):** Seção de texto explicativo abordando resumidamente a importância de gêneros como Rock, Pop e MPB.
*   **`musica.html` (Minha Playlist):** Lista com recomendações de faixas clássicas e a implementação de um reprodutor de áudio, mas não sei o porque não esta pegando.
